# 태블릿 손 테스트 체크리스트

`DESIGN.md`의 「다음 개발 작업 1번」을 실제 기기에서 확인하기 위한 문서다. 결과를 여기에 적으면 그대로 2번(수치 조정)의 입력이 된다.

## 1. 기기에서 열기

PC에서 서버를 켠다. 레포 루트(`games/`의 부모 폴더)에서:

```bash
python -m http.server 8000 --bind 0.0.0.0
```

태블릿·폰의 브라우저에 주소를 친다. **PC와 같은 Wi‑Fi여야 한다.**

```
http://172.30.1.53:8000/games/similar-kitchen/
```

| 주소 뒤에 붙이는 것 | 하는 일 |
| --- | --- |
| `?debug=1` | 오른쪽 아래에 화면 크기·배율·DPR·전체화면 여부·드래그 판정 거리를 띄운다 |
| `?seed=7` | 주문을 똑같이 재현한다. 두 기기를 나란히 비교할 때 쓴다 |
| `?debug=1&seed=7` | 둘 다 |

> PC의 IP는 바뀔 수 있다. `ipconfig`의 Wi‑Fi IPv4 주소를 쓴다.
> 태블릿이 연결되지 않으면 **VPN(NordLynx 등)을 끄고** 다시 해 본다. PC 방화벽의 「개인 네트워크」 허용도 확인한다.
> `?debug=1` 창은 오른쪽 아래 모서리를 살짝 가린다. 실제로 플레이해 볼 때는 빼고 연다.

## 2. 확인할 것

### 화면 크기
- [ ] **「굽기」 버튼과 쓰레기통이 화면 안에 다 보이는가** (이게 이번 수정의 핵심이다)
- [ ] 재료 선반의 칸 3개(반죽·식빵·스펀지)가 모두 보이는가
- [ ] 세로로 들면 「가로로 돌려 주세요」가 나오는가
- [ ] 「⛶ 전체화면」 버튼을 누르면 주소창이 사라지고 화면이 커지는가
- [ ] 전체화면에서 빠져나왔을 때 버튼이 다시 나타나는가
- [ ] 글씨가 읽을 만한가 — 특히 말풍선의 **「닮음비 1 : k」**
- [ ] 그림이 흐릿하지 않은가 (`?debug=1`의 「캔버스 ○배」가 1보다 크면 고해상도로 그리는 중)

### 끌어다 놓기
- [ ] 재료 봉지를 작업판으로 끌면 들어가는가
- [ ] 구운 빵을 손님에게 끌면 서빙되는가
- [ ] 구운 빵을 쓰레기통으로 끌면 버려지는가
- [ ] 끌고 가는 동안 따라다니는 그림이 손가락 위치와 맞는가
- [ ] 놓을 곳(접시·손님·쓰레기통)에 파란 테두리가 뜨는가

### 봉지 탭
- [ ] 봉지를 **가볍게 탭**하면 재료가 들어가는가 (끌지 않고)
- [ ] 탭할 때 손가락이 조금 흔들려도 여전히 탭으로 먹히는가 — 터치 기기는 18px까지 봐준다
- [ ] 잠긴 봉지(🔒)를 탭하면 구입되거나 「코인이 모자라요」가 뜨는가

### 오븐 탭
- [ ] 화면 아무 곳이나 탭하면 박자가 올라가는가
- [ ] **두 손가락으로 동시에 탭해도 1번만 올라가는가** (예전엔 2번 올라갔다)
- [ ] 태블릿을 쥔 손바닥이 화면에 닿아도 잘못 세지 않는가
- [ ] 박자 판정(0.7초, 오차 0.10/0.20초)이 손으로 맞출 만한가
- [ ] 기본 오븐 5번 탭이 지루하지 않은가

### 그 밖에
- [ ] 두 손가락으로 벌려도 화면이 확대되지 않는가
- [ ] 길게 눌러도 복사 메뉴가 뜨지 않는가
- [ ] 4라운드를 끝까지 하는 동안 멈추거나 느려지지 않는가

## 4. 브라우저에서 미리 확인한 값

실제 기기가 아니라 PC 브라우저의 화면 크기 흉내로 확인한 값이다. 기준 크기는 기본 1024×740, 좁은화면 900×540이다.

| 화면 | 배율 | 모드 | 잘림 |
| --- | --- | --- | --- |
| 1920×1080 (PC 모니터) | 1.000 | 기본 | 없음 |
| 1536×864 / 1366×768 (노트북) | 1.000 | 기본 | 없음 |
| 1280×800 (큰 태블릿) | 1.000 | 기본 | 없음 |
| 1024×694 (아이패드 가로, 주소창 포함) | 0.938 | 기본 | 없음 |
| 1024×600 (안드로이드 태블릿) | 0.811 | 기본 | 없음 |
| 960×545 (갤럭시탭 가로, 주소창 포함) | 0.736 | 기본 | 없음 |
| 852×350 (아이폰 가로) | 0.648 | 좁은화면 | 없음 |
| 740×320 (작은 폰 가로) | 0.593 | 좁은화면 | 없음 |

배율은 1을 넘지 않는다. PC에서는 화면이 아무리 커도 1024×740 상자가 가운데 놓인다.

4라운드 봇 테스트(`window.__api`)는 오류 없이 완주한다.

**폰은 아직 빠듯하다.** 852×350에서 배율이 0.648이라 말풍선의 「1 : k」가 화면에서 약 11px로 나온다. 태블릿(0.74~1.08)에서는 넉넉하다. 폰에서 읽기 힘들다고 나오면, 배율을 더 만지는 대신 **좁은화면에서 말풍선 안의 「1 : k」만 크게 그리는** 쪽이 맞다.
